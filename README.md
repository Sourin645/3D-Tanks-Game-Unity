# 3D-Tanks-Game-Unity
A 3D two-player tank shooter game built with Unity, featuring keyboard-based multiplayer gameplay, simple shooting mechanics, world and screen-space UI, game architecture, and audio mixing. Developed by following the Unity Tanks Tutorial.
